# Weather App 🌦️

A modern and responsive Weather Application built using HTML, CSS, and JavaScript.

## Features

* Real-time weather data using OpenWeather API
* 5-day weather forecast
* Dynamic background videos based on weather conditions
* Day and Night mode backgrounds
* Celsius and Fahrenheit conversion
* Responsive design for mobile and desktop
* Dynamic weather icons
* Search weather by city name

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeather API

## Project Preview

This application displays current weather information, forecast details, and dynamic backgrounds based on weather conditions.
